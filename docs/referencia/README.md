# Referência

- `prototipo-prumo.html` — protótipo funcional (página única). Abra no navegador do computador para
  ver o comportamento esperado das telas Dia, Semana, Mês, Ano, Matérias, adicionar rápido, ajuste de
  blocos e captura. As funções de IA e sincronização dependem do ambiente do Claude e não funcionam
  fora dele; o resto funciona offline com dados de exemplo.
- `algoritmos.md` — especificação das regras do `src/core`, com cenários de aceite.
- `design.md` + pasta `design/` — design escolhido ("Caderno"): tokens, tipografia, componentes e telas de referência.

O protótipo é referência de comportamento e visual, não de arquitetura: não copie o código dele
para o app. Reescreva seguindo `docs/02-arquitetura.md`, com testes.
